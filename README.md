# BTW-Packwiz

Beyond The Wake 整合包开发人员使用的可自动更新模组、材质包等可内容的仓库。

## 工作流程

本仓库使用 GitHub Actions 实现自动化管理：

- 每次向 `main` 主分支推送改动时，工作流会自动运行 `packwiz refresh`命令
- 若上传了新的 `.pw.toml` 元数据文件，CI 会自动检测 `index.toml` 变更情况，然后自动提交并推送更新后的索引文件

## 本地开发

> 推荐使用Prism启动器下载模组等内容。

1. 先克隆此仓库到本地。

2. 在本地下载或更新模组等内容后，手动将元数据文件复制至此仓库对应文件夹内，推送更改即可。
